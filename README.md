# MEDIFACT

Plateforme d'analyse et de prétraitement des données biomédicales.

## Auteurs

- Badr AATOU
- Mehdi HAMDAN

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- OpenPyXL
- Scikit-Learn

## Installation

```bash
git clone https://github.com/votre-compte/MEDIFACT.git
cd MEDIFACT
pip install -r requirements.txt
```

## Exécution

```bash
streamlit run app.py
```
